# Nikah Nama Personalization Spec

## Scope
This module applies only to products like `Nikah Nama` and `Premium Nikah Nama`.

## Required Inputs
- template image
- lifestyle gallery
- text zones
- font options
- character limits
- alignment rules
- min/max font sizes
- line-height and letter-spacing controls
- admin notes
- preview rules
- final render rules

## Storefront Experience
- left-side or top-first live preview
- right-side structured field controls
- safe preview updates without heavy front-end complexity
- structured personalization payload added to cart and order items

## Admin Experience
- template manager
- text zone manager
- font library
- preview configuration
- proof and final render settings

## Implementation Note
Preview rendering and final output rendering should be loosely coupled so MVP performance stays light.
