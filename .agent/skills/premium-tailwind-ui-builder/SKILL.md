# Premium Tailwind UI Builder

When designing or improving UI:

1. Use a premium, clean, conversion-focused layout.
2. Prefer Tailwind utility classes and existing Blade components.
3. Keep layout responsive for mobile, tablet, and desktop.
4. Use the project’s preferred style:
   - glassmorphism where suitable
   - soft shadows
   - rounded corners
   - subtle gradient accents
   - clean typography hierarchy
   - smooth hover/focus states

5. For ecommerce pages:
   - Product image must be visually strong.
   - Variants must be easy to select.
   - CTA must be clear.
   - Related products, related categories, and last viewed items should be organized cleanly.
   - Product image hover zoom should feel premium but not heavy.

6. Avoid:
   - cluttered cards
   - too many borders
   - weak spacing
   - inconsistent font sizes
   - oversized thumbnails

7. Before finishing:
   - Check for responsive layout issues.
   - Run pnpm build if frontend assets changed.

8. Final response must include:
   - changed files
   - UI improvements made
   - responsive behavior
   - test checklist
